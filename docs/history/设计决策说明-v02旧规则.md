# Insight-to-Post · MVP 设计决策

版本：0.2 实现 · 2026-10-06。已接入 Tavily 搜索、每次正式回复至少 5 个最终信源、最后的社交文案节点与一键复制。启动脚本从 `key.txt` 识别服务归属并填入缺失配置，已验证 Tavily 鉴权，不打印或混用密钥。验证结果单独记录，旧 v0.1 千问内置搜索验收保留为历史。

## 1. 先解决什么

核心是把一个问题变成有可定位证据的指标卡。手机上能阅读、查看片段、打开原文，研究失败与证据不足有清晰状态。一个 Next.js 应用承担页面和 Node.js 后端，无数据库、任务队列或复杂 Agent 框架，便于 Windows 一键运行。

v0.2 由后端直接调用 Tavily Search，必要时用 Tavily Extract 补取正文；千问负责报告生成、语义复核和最后的社交文案。搜索调用、来源数量与补搜预算由后端控制。Tavily 与千问使用各自的服务端密钥；正文和模型生成均已进行真实调用，端到端结果见验收记录。

## 2. 信源怎么选

优先论文、官方统计和机构研究，新闻用于补充事件背景。每次正式分析回复必须实际引用至少 5 个相关、有可用正文的独立信源，并覆盖至少两类。重复 URL、同一文章的镜像和相同转载合并计数，同一来源的多个片段只算一个；5 个信源不等于 5 张卡片或 5 类信源。

首轮检索 10 个候选，优先将最多 8 个论文、官方统计、机构材料等来源送入生成；必要时按问题中的专有名词补充英语检索。每个来源单独保留相关段落预算，避免长页面和导航挤占上下文。最多补搜一次、修复引用一次。结构与语义复核后重新计数；仍不足 5 个时仅返回不足说明与来源。complete 与 partial 均须达标。

沿用保守的来源分类，无法确定时显示未知，不以两个网站代替两类。域名分类有限，论文刊载页等边界仍可能需要人工判断。搜索链接用于回溯，正文用于证据。标题、日期缺失显示未知，不从链接年份猜测、不让模型补造。

## 3. 如何减少引用幻觉

只接受本次 Tavily 搜索返回或随后对这些 URL 提取的证据。Search 请求 raw_content，缺失时可用 Extract 补取；搜索摘要 content 用于筛选，Tavily 生成的 answer 不作为原文证据。空正文、拒绝访问页和无法识别的内容不计入有效来源。后端去重并分配 S1 等 ID，将连续证据段落再编号为 S1-E1。模型只选择来源与证据段落 ID，引用正文和原文链接均由后端映射，避免模型改写长引用。

Zod 逐项检查结构，不合格单项移除，不让一张缺失单位的卡片导致整个分析消失。再检查来源、原文片段、数字与相邻单位、时间锚点；中文样本范围、含义和因果关系由一轮模型辅助复核。多个引用须实质支持内容，有限材料不能被写成普遍共识。整份 JSON 或顶层结构异常最多修正一次。

信源状态保留“未尝试提取”“提取失败”“内容不可用”“内容已引用”，以及“已提取未引用”。状态依据实际请求、正文和最终引用判断；Search 已请求 raw_content 即算尝试过正文提取，空返回不能标为未尝试。界面显示最终有效引用数量与不足原因。

这些检查不能保证结论绝对正确：正文由 Tavily 返回，生成和复核仍为同一模型；翻译、抽样口径和来源真实性需人工核验。界面保留原文入口。无正文不填卡，无实际搜索直接失败，信源覆盖不足明确提示。

## 4. 社交文案与平台发布

分析报告帮助用户读懂问题，独立最后节点将已核验内容改写成一份适合 X 的中文文案。参考用户示例：有依据的变化吸引兴趣，短段落解释过程和影响，最后落到人的处境，引起共鸣与讨论。结尾表达交给模型，可用提问、感悟或陈述，不强制问句和问号；文风不作为拒绝条件。示例事实不自动复用，文案不能强化因果或丢掉重要限制。

新板块显示纯文字、长度、依据和一键复制，段间一个空行；界面标签、Markdown 与内部引用 ID 不进入剪贴板。文案逐段关联证据，独立检查至少 5 个实际支持来源及两类。校验失败保留报告；单独重试使用两小时有效的签名报告片段，不重复搜索或接受客户端改造的证据。复制失败提供手动全选路径。

页面默认叙述长文（2000 加权字符，提示需要 X 长帖权限），另提供标准短帖（280）。使用官方推荐的 twitter-text 计数，超限先修正，不能截断。Windows 剪贴板会归一化行结束符，实际粘贴后的段落和空行须一致。

用户自行粘贴并发布；X 与小红书的平台鉴权、直接发布、删除和幂等仍暂缓。复制文案不算完成原题 M4，后续接入发布 API 时另行核对官方准入与权限。

## 5. 砍掉了什么，为什么

原题流式响应和首字 <2 秒暂缓，研究阶段有通用加载、计时和取消，不伪造分阶段完成状态。三种模板先保留指标卡一种，对比表和时间线暂缓。生图、PNG 导出、用户登录、云历史、PWA 和公网托管均暂缓。独立搜索 API 纳入 v0.2，以落实来源数量与证据校验。达标报告可以少于三张卡片；来源不足则返回不足说明，不能为了视觉完整补数。

当前可交付本机及同 Wi-Fi 手机访问地址、一键启动、测试和实测记录。窄屏模拟不等于真手机验收；无法在当前环境代替用户的物理手机检查。公网部署需补鉴权、限流与预算管理。

配置示例、启动检查、研究链路和文案节点已更新。验收记录区分单元测试、浏览器模拟、真实 API 与物理手机结果；不以配置完成或旧两来源示例冒充新门槛通过。

接口依据：[Tavily Search 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/search)、[Tavily Extract 官方文档](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。max_results 是候选结果上限，不保证返回足量可引用正文。
